Energym

Energym is a fitness center located in Haskovo, Bulgaria. The website is in Bulgarian, however you can see the translated version in a video below.

Live Link ↗

Role & responsibilities

  • Gathered stakeholder information about the gym and the project scope

  • Created a responsive website layout

  • Configured hosting and domain setup to make a fully operational and publicly accessible website

  • Iterated the code so that the design corresponds to the stakeholder's needs

The challenge


Customers did not have the option to find more information about the facilities, opening hours and contact. The business owner wanted to make it accessible to the end users to learn more, get in touch and download the app so that they can have access to the fitness center whenever they need.



The problem


How can Energym provide visitors with quick access to relevant information while creating a professional digital presence that supports both existing members and future customers?


Users needed to:

  • Download the gym application
  • Learn about the gym and its facilities
  • Access practical information and contact details

The solution

The project was developed solely by me in close collaboration with the client, combining AI-assisted development with modern web design to deliver a simple and user-friendly solution. The solution is a responsive design for a landing page to show the most important content into a single digital source.

The website presents structured information about the location, highlights key services and facilities through visual content, and guides users towards downloading the gym application and engaging with the available services. By prioritizing simplicity and accessibility, the platform reduces the time users spend searching for information and creates a more professional customer experience.

Design & development



The project was developed using:

  • HTML
  • CSS
  • Claude AI-assisted development workflows
  • Hosting and domain configuration
A website template served as the initial foundation, allowing development efforts to focus on customization, content structure, usability, and branding.
